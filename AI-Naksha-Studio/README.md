## Local run
Open `index.html`, or run:
`python -m http.server 8000`

Then visit `http://localhost:8000`.

## GitHub Pages
Upload the CONTENTS of this folder to the ROOT of your GitHub repository, so `index.html` is directly in the repository root.

Then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
