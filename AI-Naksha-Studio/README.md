1. Extract this archive into your local clone of `https://github.com/ainakshastudio-sudo/Ai-naksha-studio`.
2. Ensure your official `assets/logo.png` and `assets/favicon.png` remain in the `assets/` folder.
3. Run:
   ```bash
   git add .
   git commit -m "Deploy redesigned 3D Liquid Glass AI Naksha Studio website"
   git push origin main
   ```
4. GitHub Pages will automatically publish the live experience at `https://ainakshastudio-sudo.github.io/Ai-naksha-studio/`.
